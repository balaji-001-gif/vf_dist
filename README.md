# FreshRoute

Farm to Customer Distribution Platform.

## Description

FreshRoute is an ERPNext custom application designed for vegetable and fruit distribution, managing workflows from farmer procurement to customer delivery.

## Installation

You can install this app using the frappe bench:

```bash
bench get-app freshroute https://github.com/your-username/freshroute.git
bench --site [your-site-name] install-app freshroute
```

## Features
- Farmer Management
- Vehicle & Route Management
- Crop and Procurement Lifecycle
- Quality Control
- Cold Storage
- Customer Orders
